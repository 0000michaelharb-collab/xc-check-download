# XC Check

**Check. Pack. Fly safe.**

XC Check behält deinen Gleitschirm, deine Rettung, dein Gurtzeug und deine Tandemberechtigung im Blick und erinnert dich rechtzeitig per Push-Nachricht vor jedem fälligen Check.

## Download für Android

**[XC Check herunterladen](https://github.com/0000michaelharb-collab/xc-check-download/releases/latest/download/XC-Check.apk)**

1. Link am Android-Handy öffnen, die Datei wird geladen.
2. Datei antippen. Beim ersten Mal fragt Android, ob der Browser Apps installieren darf: **Zulassen**.
3. **Installieren** tippen. Falls Google Play Protect warnt: **Trotzdem installieren**.

## Gratis und Pro
