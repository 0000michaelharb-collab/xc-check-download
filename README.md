## Häufige Fragen

**Wie oft muss ein Gleitschirm zur Nachprüfung?** Das Intervall gibt der Hersteller im Betriebshandbuch vor, meist 24 Monate oder eine Stundengrenze.

**Wie oft muss der Rettungsschirm gepackt werden?** Laut Hersteller, üblich ist einmal pro Jahr.

**Wann muss ich die Tandemberechtigung verlängern?** In Österreich ist alle 3 Jahre ein Überprüfungsflug nötig, geflogen in den letzten 12 Monaten vor Fristablauf.
